# NPC 비용 절감 프로젝트

게임 속 AI NPC의 대화 비용과 응답시간을 측정하고, 캐싱·프롬프트 축약 등 비용 절감 방법의 효과를 비교하는 프로젝트입니다.

- **프로젝트 유형:** 데이터 수집·분석 중심
- **목표 사용자:** 생성형 AI NPC를 만들려는 1인·소규모 게임 개발자
- **개발 기간:** 약 4주
- **핵심 목표:** NPC 답변 품질을 함께 확인하면서 비용과 응답시간을 줄일 수 있는 조건을 실험으로 찾습니다.
- **현재 기준 버전:** 0.4

> 30% 비용 절감은 확정된 결과가 아니라 실험으로 확인할 목표입니다. 실제 절감률은 실행 결과를 바탕으로 계산합니다.

## 2. 프로젝트 개요

### 2.1 해결하려는 문제

AI NPC가 대화할 때마다 모델 호출 비용이 발생할 수 있고, 대화가 길어지면 입력 토큰과 응답시간이 늘어날 수 있습니다. 개발자는 어떤 절감 방법이 자신의 NPC 대화에 효과적인지, 비용을 줄인 뒤에도 답변 품질이 유지되는지 확인할 필요가 있습니다.

### 2.2 실험 방향

| 비교 방식 | 설명 |
|---|---|
| 기본 방식 | 최적화 방법을 적용하지 않고 NPC 답변을 생성하는 기준 방식 |
| 캐싱 | 이전에 처리한 동일·반복 요청의 결과를 재사용하는 방식 |
| 프롬프트 축약 | AI에 전달하는 NPC 설정과 대화 내용을 줄이는 방식 |

각 방식의 토큰 수, 예상 비용, 응답시간을 비교하고 NPC 답변 품질은 사람이 평가합니다.

### 2.3 확인된 사실과 검증할 가설

**기획에서 정한 내용**
- 기본 방식, 캐싱, 프롬프트 축약을 비교 대상으로 정했습니다.
- 비용과 응답시간은 실행 결과를 바탕으로 기록합니다.
- 답변 품질은 사람이 확인합니다.

**실험으로 확인할 가설**
- 캐싱과 프롬프트 축약이 예상 사용 비용을 줄일 수 있는가?
- 비용을 줄인 뒤에도 NPC 답변의 말투와 설정이 유지되는가?
- 특정 실험 조건에서 30% 이상 절감할 수 있는가?

## 3. 현재 프로젝트 폴더

```text
-AI--main/
├── README.md
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── data-loader.js
│   └── script.js
└── data/
    ├── Generated_info.json
    ├── Generated_info.jsonl
    ├── npc_dialogue.json
    ├── npc_dialogue.jsonl
    └── npc_samples.json
```

| 경로 | 역할 |
|---|---|
| `index.html` | 웹 화면의 기본 구조 |
| `css/style.css` | 화면 디자인과 배치 |
| `js/script.js` | 화면 동작과 사용자 입력 처리 |
| `js/data-loader.js` | 데이터 파일을 불러오는 기능 |
| `data/Generated_info.*` | 생성 정보 데이터 |
| `data/npc_dialogue.*` | NPC 대화 데이터 |
| `data/npc_samples.json` | NPC 샘플 데이터 |

JSON과 JSONL은 같은 종류의 데이터를 서로 다른 형식으로 저장할 때 사용합니다. 파일이 존재한다는 사실만으로 모든 실험 기능이나 실제 AI 모델 연결이 완료되었다는 뜻은 아닙니다.

## 5. 실험 데이터 및 평가 기준

실험을 진행할 때 다음 항목을 기록하는 것을 기준으로 합니다.

- 실행 번호와 NPC 정보
- 적용한 방식(기본·캐싱·프롬프트 축약)
- 입력·출력 토큰 수
- 예상 비용과 응답시간
- 캐시 사용 여부
- NPC 답변
- 사람이 평가한 답변 품질

**비용 계산**

`예상 비용 = (입력 토큰 수 × 입력 토큰 단가 + 출력 토큰 수 × 출력 토큰 단가) ÷ 1,000,000`

`절감률(%) = (기본 방식 비용 - 최적화 방식 비용) ÷ 기본 방식 비용 × 100`

예상 비용은 입력한 모델 단가를 이용한 계산값입니다. 실제 결제 금액과 혼동하지 않도록 구분합니다.

**답변 품질 평가 기준**
- 써도 됨
- 애매함
- 안 됨

실험 결과가 나오기 전에는 비용 절감률이나 품질 유지 여부를 확정된 성과로 표현하지 않습니다.
