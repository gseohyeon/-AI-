프로젝트명: NPC 비용 절감
프로젝트 유형: 데이터 수집·분석 중심
개발 기간: 약 4주
목표 사용자: AI NPC를 만드는 1인·소규모 게임 개발자

1. 프로젝트 소개

1.1 프로젝트 정의

게임 속 AI NPC가 대화할 때 드는 비용과 시간을 측정하고, 비용을 줄이는 방법을 비교하는 웹 서비스이다.

1.2 프로젝트 목표

실제 AI로 NPC 대화 생성

기본 방식, 캐싱, 프롬프트 축약 비교

토큰 수, 예상 비용, 응답시간 측정

NPC 답변 품질 평가

결과를 표, 그래프, CSV 파일로 정리

회원가입 및 로그인 기능 제공

최종 목표: NPC의 답변 품질을 유지하면서 비용을 줄일 수 있는 방법을 찾는다.

2. 사용자·문제·가치

2.1 목표 사용자

AI NPC를 만들고 싶은 1인·소규모 게임 개발자

2.2 해결하려는 문제

AI NPC는 대화할 때마다 비용이 발생한다. 대화가 길어지면 비용과 응답시간이 늘어날 수 있다.

개발자는 어떤 방법이 비용을 줄이는 데 효과적인지, 답변 품질은 유지되는지 확인하기 어렵다.

2.3 제공할 가치

비용 비교: 절감 전후 예상 비용 확인

속도 비교: 답변 생성 시간 확인

품질 평가: NPC 답변이 적절한지 평가

결과 저장: 실험 결과를 CSV로 다운로드

5.2 비용 계산

예상 비용 = (입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가) ÷ 1,000,000

절감률 = (기본 비용 − 절감 후 비용) ÷ 기본 비용 × 100

예상 비용은 사용자가 입력한 단가로 계산하며, 실제 결제 금액과 구분한다.

PRD 0.2 최종 요약

NPC 비용 절감은 AI NPC의 대화 비용과 응답시간을 측정하고, 기본 방식·캐싱·프롬프트 축약을 비교하는 웹 서비스이다.

사용자는 닉네임과 비밀번호로 로그인하고 NPC 실험을 진행한다. 실험 결과는 표, 그래프, CSV 파일로 확인할 수 있으며, 답변 품질은 사람이 직접 평가한다.

최종 기능 우선순위

Must Have: 11개

Should Have: 3개

Could Have: 1개

가장 중요한 목표는 실제 측정 결과를 바탕으로 NPC의 비용을 줄이면서 답변 품질을 유지할 수 있는지 확인하는 것이다.
